# Research Branch

研究のステップを **git の commit / branch のように** 記録するローカルアプリです。
先行研究のサーベイ、実験プログラム、結果、考察…を順番に積み上げ、出戻りが起きたらその地点から **分岐** して新しい筋を伸ばせます。
実験が終わったら、採用した筋を上から辿るだけで論文の構成ができあがります。

GitHub の履歴管理と Obsidian のノート（Markdown・画像・`[[リンク]]`）を合わせたような使い心地を目指しています。

## 特徴

### 記録（commit）
- タイトル・本文（Markdown）・タグ・リンク（論文URL / DOI / コードのパスなど）を、現在のブランチ（HEAD）の続きに追加
- 本文にはコードブロックや表も書ける。プレビュー付き

### 分岐（branch）
- グラフ上で過去の記録を選び「⑂ ここから分岐」で、その地点から新しい筋を開始
- ブランチには **進行中 / 採用 / 棄却** の状態と、分岐の理由を残せる
- グラフは上が古く下が新しい（論文と同じ向き）。棄却した筋は点線で表示、非表示にもできる

### タグと検索
- 「先行研究」「実験プログラム」「実験結果」「考察」などの基本タグを用意（追加・色変更・並べ替え可）
- タグの OR / AND 絞り込みとキーワード検索。一覧ビューではタグごとにまとめて表示

### 論文構成
- 採用するブランチを選ぶと、最初の記録から先端までの一本の筋を番号付きで表示
- 途中で分かれた筋（棄却した案など）を「検討した別の筋」として分岐点に理由付きで併記
- 「ロジック順」と「タグ別に章立て」を切り替え、Markdown でコピー / `.md` 保存

### Obsidian 風の機能
- **画像・ファイル添付**: 本文への貼り付け（Ctrl+V）、ドラッグ＆ドロップ、「📎 添付」ボタン。PDF・CSV・動画なども可
- **`[[記録のタイトル]]` リンク**: 他の記録へリンク。リンク先には **バックリンク** を表示。タイトルを変えるとリンクも追従

## 使い方

必要なもの: [Node.js](https://nodejs.org/) 18 以上

### かんたん起動（Windows）

`app/start.bat` をダブルクリックすると、初回は自動でセットアップしてから http://localhost:4173 をブラウザで開きます。
終了するときは黒いウィンドウを閉じてください。

### コマンドで起動

```bash
cd app
npm install
npm run build
npm start          # http://localhost:4173
```

開発モード（ホットリロード）:

```bash
cd app
npm run dev        # http://localhost:5173
```

### 基本の流れ

1. 「新しいプロジェクトを作る」（または「サンプルを見てみる」）
2. 「＋ 記録する」で研究のステップを記録していく
3. 出戻りが起きたら、戻りたい記録を選んで「⑂ ここから分岐」
4. うまくいかなかった筋はブランチの状態を「棄却」に、論文にする筋は「採用」に
5. 「論文構成」タブで採用ブランチを選び、Markdown として書き出す

## データの保存

- すべて **このPCの `app/data/` フォルダ** に保存され、インターネット接続は不要です
  - `data/db.json` … 全プロジェクトのデータ（自動保存）
  - `data/backups/` … 10分おきの自動バックアップ
  - `data/attachments/` … 添付した画像・ファイル
- `data/` は `.gitignore` 済みで、リポジトリには含まれません
- プロジェクト設定（⚙）から全データを JSON で書き出し / 読み込みできます

## 構成

```
app/
├─ src/
│  ├─ App.tsx              画面全体・ダイアログ
│  ├─ store.ts             データモデルの操作と保存
│  ├─ graph.ts             コミットグラフのレイアウト
│  ├─ wiki.ts              [[リンク]]・バックリンク・添付
│  ├─ sample.ts            サンプルプロジェクト
│  └─ components/          グラフ / 一覧 / 論文構成 / 詳細パネル など
├─ api.mjs                 ローカル保存 API（db.json と添付ファイル）
├─ server.mjs              本番用サーバー（npm start）
└─ start.bat               Windows 用ランチャー
```

技術: React 18 + TypeScript + Vite、Markdown 表示に marked。サーバーは Node.js 標準モジュールのみ。
